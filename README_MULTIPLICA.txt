MULTIPLICA - Hagamos la tarea
Prototipo web funcional

CONTENIDO
- index.html: pagina principal del prototipo.
- css/styles.css: estilos visuales, responsive y modo claro/oscuro.
- js/app.js: interacciones del mapa, mentor IA simulado, dashboard, timeline y laboratorio IA.
- sw.js: soporte basico offline/cache cuando se abre desde servidor local.
- assets/community-lab.png: imagen principal del prototipo.

COMO USARLO
Opcion rapida:
1. Abre index.html con doble clic.
2. La experiencia visual e interactiva funciona sin instalar dependencias.

Opcion recomendada para activar modo offline:
1. Abre PowerShell dentro de esta carpeta.
2. Ejecuta:
   python -m http.server 4173 --bind 127.0.0.1
3. Abre en el navegador:
   http://127.0.0.1:4173

NOTAS
- No requiere internet.
- No requiere instalar paquetes.
- Esta optimizado como prototipo liviano para celulares y computadores.
- Para editar textos, modifica index.html.
- Para cambiar colores o estilos, modifica css/styles.css.
- Para cambiar interacciones, modifica js/app.js.
